# Werf — releases

Hier staan alleen de installer en de automatische updates van de Werf Windows-app (gemaakt met [Velopack](https://velopack.io)). De broncode staat in een privé repo.

**Installeren:** download `Codios.Werf-win-Setup.exe` bij de [laatste release](../../releases/latest). Windows SmartScreen vraagt de eerste keer om bevestiging (*Meer informatie* → *Toch uitvoeren*). Daarna werkt de app zichzelf bij.
